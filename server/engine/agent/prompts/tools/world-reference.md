## 目录结构

任务根就是这个世界现在的样子，不是「要交付的东西」：

- `世界.md` — 世界书。**冻结层**，只在章末 / 场末结算时改写，平时不动。
  它是形态判定证据，删了这个任务就不是 world 了。
- `事件.md` — 追加层。世界级变化先记这里，结算时并进世界书。
- `世界/` — 空间结构根。文件夹树就是地图。
- `关系/` — 关系文件平放，一对角色一个文件，文件名按角色名字典序连接，
  保证一对只有一份。不要把关系写进某个角色的文件夹里，两边各存一份必然漂移。
- `dist/` — 只放导出物（仿书 html 之类）。世界状态不进这里。

## 节点类型靠内容判定，不靠命名

一个文件夹装着哪份说明文件，它就是哪种节点：

| 装着 | 是什么 |
|---|---|
| `地点.md` | 地点。可以套子地点，也可以装角色文件夹 |
| `角色.md` | 角色。里面只放这个角色自己的东西，不装别的角色 |
| `容器.md` | 收纳容器，**不是地点**。存暂时不在任何场景里的角色 |

所以文件夹想叫什么叫什么，中文、空格、emoji 都行，重命名不会弄坏任何东西。

## 角色文件夹里的四个面，生命周期完全不同

- `角色.md` — **当前状态**。每场都可能变，一旦过期就崩人设，必须保持最新。
- `背景故事.md` — 写一次基本不动。纯缓存料，不要没事重写。
- `经历.md` — 只增不减。**不要全文读**，会撑爆上下文；要旧事用检索。
- `立绘/prompt.md` — 生图 prompt 片段，**冻结，不要改**。一改角色跨图就不像同一个人。

## 上下文纪律

每轮只该在上下文里的：当前地点、它的背景、**在场**角色的当前状态、
本章大纲或悬线、近期对话。

背景故事和经历不进每轮注入，需要时按需读。不在场角色的任何东西都不该进。
把一个角色拖下场，就是把他的状态移出 prompt。
