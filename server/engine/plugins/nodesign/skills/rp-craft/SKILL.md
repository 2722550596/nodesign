# 一场演出是什么

三样东西住在**一个文件夹**里，缺一不可：

1. `编排.yaml` —— 上下文的播放单（进模型的一切按它拼）
2. 设定文件 —— 角色、世界、文风，自由组织，被播放单引用
3. `index.html` —— 演出页。有它这个文件夹就会被认成站点，用通用站点窗打开

对话记录 `对话.jsonl` 和摘要 `摘要.json` 演出中自动生成。**摘要是派生态，永远别手写。**

台上说话的是 **chatai**：一次纯补全调用，没有工具、没有会话、改不了任何文件。
你（agent）只负责搭台和调台，不在台上。演出的每一轮花费按平台单价表记入用户额度。

# 机制契约（这一节照抄不走样）

## 编排.yaml 全貌

```yaml
模型: gemini-3.7-flash   # 可省 = 平台默认。摘要可单配便宜的（摘要.模型）
最大输出: 400            # RP 短回合是质量旋钮：300–600 合适，放大了戏会水
上下文预算: 60000        # 输入侧预算：系统层和尾部照给，历史是弹性区被从最旧挤压

系统层:                  # → system 参数。整区冻结，是缓存的本体
  - 名字: 身份与规则
    文件: 设定/老芦.md
  - 名字: 世界观
    文件: 设定/夜行集市.md
  - 名字: 文风
    内容: |
      第二人称现在时，只写可感知的事，结尾留一个能接的动作或问题。

历史:
  保留轮数: 40           # 硬上限；预算不够时还会再被挤

摘要:                    # 滚动前情提要：活历史攒到触发轮数就折叠一次
  保留轮数: 12
  触发轮数: 24           # 必须 > 保留轮数，差值是滞回区间
  长度: 500

尾部:                    # → 拼进当轮 user 消息前部。唯一允许每轮变的区
  - 名字: 当前场景
    文件: 状态/场景.md    # 谁改这个文件，下一轮就生效
  - 名字: 交易提醒
    内容: 涉及买卖时报价要具体到铜币数目。
    触发: [买, 卖, 价钱]  # 触发词命中最近几轮或当轮输入才插入
    # 停用: true          # 播放单开关
```

铁律三条：条目 `文件`/`内容` 二选一；**触发条目只能住尾部**（住系统层直接拒开演）；
文件引用不许跑出演出文件夹。配置错了端点会拒演并报人话，照改就是。

## 两条 API（演出页用，cookie 同源自动带）

- `GET /api/projects/<pid>/chatai/log?dir=<文件夹>` → `{records, 摘要, 配置}`，开场铺台用
- `POST /api/projects/<pid>/chatai/turn` body `{dir, input}` → SSE 流：
  `data:{delta}`… 最后 `data:{done, text, usage, costUsd}`；错误 `data:{error}`。
  拒绝码：429 太快或额度尽、409 上一轮没回完、403 账号未开通演出通路

## 开场白（角色先开口）

往 `对话.jsonl` 种第一条记录：

```
{"seq":1,"role":"assistant","text":"<开场白>","at":"<ISO时间>"}
```

它不算轮数，够老了会随摘要折叠。用户视角：一进场角色已经在说话。

# 三区纪律 —— 为什么这么摆

顺序即上下文：**稳定的在前吃缓存，易变的在后换自由。** 缓存按字节精确匹配前缀，
前缀里任何一个字变了，它后面的一切全部重算。

反面教材是酒馆的世界书：几百个词条按关键词触发、插在前缀中段，每轮触发集一变
后面全废 —— 实测 573 条词库缓存命中率 **0%，一轮一美元**。所以这里触发条目被
结构性关进尾部：尾部本来就在最新对话之后、缓存必然失效的位置，触发集怎么变都
伤不到前缀。

「每轮允许多大范围变化」是用户的取舍旋钮，空间化了：一段内容放系统层 = 冻住换
缓存，挪尾部 = 放开换灵活。用户要"自由一点"，就是把东西往尾部挪。

# 特化菜谱（参考，不当分类）

**身份与规则**（系统层第一条）：演谁、对用户用什么人称、回合怎么接（只推进一拍，
别替用户行动）、回复长度、这场戏的禁区。这一条的质量决定八成体验。

**世界观：整本冻结，别切条。** 这条路是 1M 窗口 + 便宜的 flash，几万字设定冻在
系统层一次写进缓存，比切几百条按关键词捞又稳又便宜。酒馆玩家的切条肌肉记忆是
8k 窗口时代逼出来的，别带过来。

**文风锚**：三五条"怎么写"的约束 + 一小段范文，比一堆形容词管用。范文是最强的锚。

**状态文件当活道具**：`状态/场景.md` 这类尾部条目，演出中你或用户改文件就等于
改状态，不需要任何变量系统。复盘时读 `对话.jsonl`，该收线时改状态文件推剧情。

**触发条目 = 导演小纸条**，一场十条以内：战斗时收紧节奏、某个名字出现时提醒一段
旧怨。它是"到了这一幕才递的条子"，不是知识检索。

**酒馆 V2 卡迁移**：读卡 JSON —— `description/personality/scenario` 并成一份角色
文件进系统层；`first_mes` 种成开场白；`mes_example` 提炼进文风锚；`character_book`
里 constant 的并进世界观、触发型的挑十条以内做成尾部小纸条，其余并进世界观正文。

# 建场流程

1. **先问再动手**：题材与基调、角色是谁跟用户什么关系、文风参照（有没有喜欢的
   作品口吻）、回复长短、禁区、谁先开口。两三个问题一起问，别拷问。
2. 落设定文件和 `编排.yaml`，要开场白就种上。
3. 造 `index.html`：**管线整段照抄 `patterns/演出页-最小实现.html`**（URL 自省、
   铺场、SSE 解析、错误处理、输入法回车判定 —— 这些是协议不是设计，现写必错），
   **皮肤按题材重设计**：字体、色纸、气泡形态、台面装饰都是戏的一部分。手机窄屏
   必须能玩。
4. 自检：screenshot 演出页，确认铺场正常、开场白在台上。第一轮留给用户开。
5. 告诉用户：点开这个文件夹的站点窗就能进场；想调口味（换文风、改场景、挪冻结
   范围）随时叫你改 —— 你就是这场戏的场务。

# 价钱小抄（跟用户聊配置时用）

gemini-3.7-flash：$0.75/M 入、$3.75/M 出（促销价，思考 token 计入输出且关不掉，
约为正文两三倍）；claude-sonnet：$3/$15。一轮典型 RP（几千字上下文、几百字回复）
flash 约 $0.003–0.008。预算紧就守住：最大输出别超 600、上下文预算 4–6 万。

# 边界

- 页面里永远不出现任何密钥（不需要：端点靠 cookie）。
- 页面不做定时轮询、自动重发 —— 限频闸会拦，但根上就别写。
- 演出内容平台不审（chatai 无工具无副作用），尺度是用户和角色设定之间的事。
