# Text-led（layout-role: `text-led`）

文字主导页：论点页 / 结论页 / 痛点页 / 概念页。文字承载叙事，图（如有）只是配重。

## 意图

这页靠一句锋利的话立住。核心句是主角，其余段落和要点是它的证据链。
跟 hybrid 的区别看图文权重：图超过三成注意力就该走 hybrid。

## 真正硬的几条

- **核心句只有一个**。标题写结论不写名词（"市场规模" → "AI 搜索市场在升级为基础设施"）。
- **文字量有天花板**：演示稿不是文档，段落多到要缩小字号才装得下，就拆页。
- **要点列表膨胀是信号**：五六项以上的并列要点说明结构错了，该换卡片阵列或 Tabs，
  或者砍。
- 配重图就是配重：干净裁切即可，别套 cover 那套 overlay。

## 写法

大留白单句页、左文右图、纯文居中都是合法形态，从锚的版式语言推导。
section 常规三件套标记；关键文字元素加 `data-anchor` 方便跨 turn 引用。
