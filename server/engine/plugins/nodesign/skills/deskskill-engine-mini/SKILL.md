# 核心守则：先找到那一份，再做整套

一个 deck 做砸，几乎不是排版技巧的问题，是**没跟用户对上他想要的样子就开始铺量**。
铺完再改等于重做，用户也说不清哪里不对，只会说"感觉不是这个味道"。

所以顺序永远是：

**试作 → 给看 → 改 → 用户说"就这个" → 锚定 → 铺开整套**

试作阶段一次只做一页（通常是封面，或者最能代表调性的那页），做真的、可看的，
不是描述。用户看着实物给反馈，比看你写"暖调克制风"准一个量级。
方向没定之前不要往后铺页，铺了就是在给自己制造返工。

## 形态从一个问题长出来

风格之前还有一层：**这份东西在什么场合被谁消费，看完要发生什么？**
关键分叉是"讲的时候有没有人在场"——有人讲，页面是讲话的背景板，字少图大
节奏归讲的人；没人讲，页面自己要把话说完，密度和完整性归页面。
答案定了，页数、密度、比例、语气自己长出来。

几个常见答案长出来的样子，当参考不当分类：

- 「投资人听完想约下一次」→ 少字大图，一页一击，节奏有起伏，结尾收在行动上
- 「自己读完就得懂」→ 信息完整优先，页可以密，图表带完整标注，读感像文档
- 「课堂上跟着讲」→ 概念逐步展开，一页一步，前后页强连贯
- 「一张图发出去」→ 海报 / 竖版长图，单件作品，全部力气砸在一屏里

不在这几种里的（婚礼流程册 / 菜单 / 展签……）照样用那个问题现推，别硬套。
brief 里读不出场合就问一句 —— 这一步答错，风格做得再好也是给错的东西抛光。
比例四档的选择（prelude 硬规则）就该从这里的答案顺下来，而不是单独拍。

## 试作怎么做

- **先拿参照**：brief 里出现品牌 / 产品 / 作品 / 风格名，先 `web_search { include_images: true }`
  看真图；有主体或隐喻就 `generate_image` 出一两张。看得见的东西才对得齐。
- **一次给 2-3 个方向，不要一个**：单个方案用户只能说好或不好，并排才能说出
  "左边的字，右边的颜色"。方向之间要真的不同（不是同一版调色差一点），
  差异用 `preview` 字段让用户直接看（语法见 prelude）。
- **快**：试作页允许糙，占位文字、灰块占图都行，它的任务是把风格说清楚，不是交付。
- **一轮不够就再来一轮**，用户的话往往是"再冷一点""字太挤"这种相对量，
  改完再给看。这几轮是整个项目最值的时间。

用户说"你看着办"通常是描述不出来，不是没偏好。这种情况直接做两个方向给他挑。
明说赶时间的，用模板兜底起步，但仍然要先给一页看过再铺。

## 锚定

用户点头之后，把这一份固化下来，它就是后面所有页的基准：

- `<style id="design-tokens">` 的 `:root` 整组写死（色号、字号、字体链）
- `record_decision({ topic: 'style-anchor', ... })` 记一句话："这个 deck 的样子是 X"
- 品牌类项目顺手更新 `agent-memory/brand/memory.md`

锚一句话说不出口，说明还没定下来，回去再试一轮。

## 铺开

每页只回答一个问题：**这一页用锚的语言怎么说这件事**。

- 一页一个核心句，一个视觉主角。盖住其他文字只看它，讲不清就砍。
- 相邻页拉开节奏：满与空、图与字。整套下来页页同构就成了 PDF。
- 说不出用意的装饰，删。
- 中途觉得锚不对，停下来跟用户说，不要一页一页悄悄漂过去。

写到第 8 页的用色和字体决策，应该跟第 1 页出自同一个锚。

## 页内系统（锚定时一起固化进 tokens）

**字号跨度敢拉大**。deck 是一屏一屏看的，不是凑近读的 —— 核心句 72~160px、
正文 20~28px、注脚 14~16px，跨度小了整页就平。层级用两三个维度做足
（字号 + 字重 + 颜色深浅），别每级只放大一点。

**间距用一套刻度**（如 8 的倍数），页内块间距明显大于行间距 —— 一页的"呼吸感"
靠块间留白，不靠缩小字号腾地方。中文正文行高 1.6~1.8（deck 比网页可以略紧），
字距 0.03~0.06em，字体链 latin 段后必须跟 CJK 段（`'PingFang SC', 'Noto Sans SC'`），
细字重（300 以下）别用在小字号汉字上。

**色彩：一个主色 + 一套中性灰梯度**。主色小面积用（强调词 / 数据 / 细线）才有
分量，整页铺主色是海报的事。文字别用纯黑纯白 —— 深色往主色方向偏一丝，
整套 deck 的温度就是这么来的。灰要成梯度（正文 / 次要 / 注脚 / 线），全套复用。

**图像**：全幅大图压字只压文字落脚的局部（详见 patterns/image-led-cover.md）；
`generate_image` 出的主体可以 `remove_background` 抠成透明叠层用 —— 人物半身像
出血压边（patterns/portrait.md）、物件散落在大字周围，比规规矩矩放在框里生动
一个量级。抠图记得 `filter: drop-shadow(...)` 贴地，别用 box-shadow（会给透明区
画矩形影子）。

**动效是调味**：模板里 gsap / framer-motion 都在，但一套 deck 一两种动效语言
就够（进场淡入 + 一处强调动画）。每页都动的 deck 像广告牌，不像陈述。

## 反默认清单

下面这些是 AI 视觉的统计均值 —— 出现任何一条，说明那里**没有做设计决策**，
只是滑进了模型的默认输出：

| 均值 | 它替代掉了什么思考 |
|---|---|
| 等高卡片网格（3-4 张同尺寸平铺） | 这几件事真的同等重要吗（不等重就左大右小 / 单 hero + 注脚） |
| emoji 当视觉主角 | hero 位到底该放什么：大字 / 真图 / 数据 / 形状 |
| 浅色 wash 渐变 + 浮动圆点 | 背景在为哪句话服务 |
| 每页顶一个彩色 chip 当 label | 章节感要不要独占一页转场（大编号 + 一句概括） |
| 相邻页同版式复用 | 节奏：满↔空 / 图↔字 / 静↔动，翻页要有呼吸 |

铺完扫一眼，命中的地方回去把被跳过的那个问题答了 —— 答案可以恰好是默认形态，
但要是选出来的，不是滑出来的。锚存在的意义之一，就是让这些默认无处可套。

## 修改进来时

先分清是**锚内**还是**动锚**：换字号、改文案、换图、调间距是锚内，直接做；
换主色、换字体气质、"改冷酷一点"是动锚，先跟用户点明"现在是 X，你要 Y，
我把已有页一起对齐过去？"，确认后更新锚的落档并全局传播，不留一半旧一半新。
分不清就按动锚处理。
