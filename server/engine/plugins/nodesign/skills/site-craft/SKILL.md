# 核心守则：先定气质，再铺页

跟 deck 同一条路：**试作 → 给看 → 改 → 用户说"就这个" → 锚定 → 铺开**。

区别在试作做什么。deck 试作一页封面；站点试作**首页的上半屏加一段正文** —— 站点
的气质八成由正文排版决定，只做个漂亮 hero 给用户看，等铺到正文那天他会说"怎么
跟我想的不一样"。

## 站点的气质根基是三个数

先定死这三个，再谈配色和插图：

- **字距**（`letter-spacing`，中文正文 0.05~0.08em 之间差别很大）
- **行高**（`line-height`，中文正文 1.75~1.95；比英文站需要的高）
- **正文宽**（`max-width`，中文 780~900px 之间；一行 35~45 字最舒服）

这三个数一改就是换气质，改配色只是换衣服。锚定的时候把它们写进 `:root`。

## 手写，不引框架

一份 `index.html` + 一份 `style.css` 起步，多页就同目录再加 `.html`。

**不要引 Hugo / Astro / Next / React SPA / 构建步骤。** 模板系统会把手作感吃掉，
而且用户改不动 —— 他要的是一个能自己动手改一句话的站，不是一个要 `npm run build`
才能看的工程。Tailwind CDN 也别用：站点的样式集中在一份 CSS 里才好维护，
utility class 散在几百个标签上，改行高要改一百处。

## 中文排版基线

- 标点用**全角**（，。：；？！……），半角逗号冒号在中文里很扎眼
- 字体链每段 latin family 后面必须跟 CJK family：
  `'Inter', 'PingFang SC', 'Noto Sans SC', system-ui, sans-serif`
  少了 CJK 那段，换台机器中文就掉到系统默认字体
- 字重 400 起步。300 在 13~15px 的汉字上会糊笔画，气质靠行高字距留白撑，不靠细体

## 响应式

一到两个断点就够，不要追求全档位：

```css
@media (max-width: 860px) { /* 单栏、正文宽改成 100% - 边距 */ }
```

**做完必须自己看过三个宽度**：`screenshot_canvas { device: 'mobile' }` 是真的按
390px 渲染，不是把桌面版缩小 —— 媒体查询有没有生效只有这样才看得出来。

## 反默认清单（AI 网页的均值回归）

| 默认套路 | 替代方向 |
|---|---|
| 全宽 hero + 居中大标题 + 渐变背景 | 左对齐、正文宽以内、一句话说清这是什么 |
| 三张等高功能卡片平铺 | 长文＋小标题，或图文交错 |
| emoji 当图标 | 不放图标，或一张真图 |
| `box-shadow` 卡片堆叠 | 一条 1px 分隔线，或纯留白 |
| "Get Started" / "了解更多" 按钮组 | 一条正常的句子里嵌一个链接 |
| 每段配一个渐变色块 | 通篇一个主色，只用在细线和链接上 |

命中两条以上就回去改。

## 铺开时

- 每一页只回答一个问题，导航里说得清它是什么
- 页与页之间用**相对链接**（`about.html`、`posts/x.html`），绝不用 `/about.html`
- 所有页面共用同一份 `style.css`，页面自己不写 `<style>`（除非只有这一页用得上）
- 站内链接指向的文件必须真的存在 —— `list_pages` 会给你断链清单，做完看一眼
